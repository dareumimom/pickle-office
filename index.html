      💌 실시간 합동 채팅방

      로컬 모드 — 이 브라우저에만 기록됩니다. ·

      ⚙️ 연결 설정

      🔒 API 키는 이 브라우저(localStorage)에만 저장되고, 어디로도 보내지 않아요. 키를 쓰는 순간에도 해당 AI 회사 서버에만 직접 전달됩니다. 이 페이지는 공개 주소라 링크를 아는 사람은 볼 수 있어요 — 개인 메모는 올리지 마세요.

      🔥 실시간 DB (Firebase Realtime Database)

      URL을 넣으면 반짝이·신비가 같은 방을 함께 봅니다. 주소 뒤에 ?db= 를 붙여 들어와도 자동 연결돼요.

      연결 안 됨

      Firebase 준비 방법 & 보안 규칙
      1. Firebase 콘솔에서 프로젝트를 만들고 Realtime Database를 시작합니다.
      2. 데이터베이스 URL(예: https://abc-default-rtdb.firebaseio.com)을 위에 붙여 넣습니다.
      3. 규칙(Rules)은 아래처럼 넣으면 이 방만 공유됩니다. (누구나 읽고 쓸 수 있으니 개인정보는 넣지 마세요.)
      {
  "rules": {
    "office": {
      ".read": true,
      ".write": true
    }
  }
}

      반짝이·신비에게도 이 주소를 알려 주면 같은 방에서 읽고 씁니다 — 메시지는 /office/messages/<id>, 할 일은 /office/tasks/<id>, 캐릭터 위치는 /office/chars/<이름>.

      ✨ 제미나이 (Gemini API Key)

      키를 넣으면 채팅에서 @제미나이를 부를 때 브라우저에서 바로 답해요. 무료 키도 됩니다.

      키 없음
